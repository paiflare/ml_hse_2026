## Оценка
```Итог = 0.4*ДЗ + 0.1*Сем + 0.5*Экз```

* `ДЗ` - Средняя оценка за задания с 1 по 5.
* `Сем` - Оценка за мини-тесты и работы, выполненные на занятиях.
* `Экз` -  Оценка за экзамен.
