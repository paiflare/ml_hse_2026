# Неделя 6. Классификация текстов: Bag of Words и TF-IDF

**Семинарист:** Иван Горбунов

[`06_Text_Classification_BoW_TFIDF.ipynb`](06_Text_Classification_BoW_TFIDF.ipynb) — основной ноутбук семинара.

## О чём

Как превратить текст в матрицу признаков и обучить на ней логистическую регрессию. Задача — тональность новостей на русском (3 класса).

1. Данные
2. Бейзлайн
3. Bag of Words
4. TF-IDF
5. Нормализация текста: лемматизация и стоп-слова
6. Что влияет на качество: n-граммы, размер словаря, регуляризация
7. Интерпретация модели: веса слов, объяснение отдельного предсказания, разбор ошибок
8. Сравнение с деревьями
9. Наивный Байес против логистической регрессии

## Что понадобится

```
pip install numpy pandas matplotlib seaborn scikit-learn nltk pymorphy3
```

`pymorphy3` и `nltk` ставятся первой ячейкой ноутбука, так что после клонирования достаточно Run All — в том числе в Colab.

Данные (~57 МБ) скачиваются первой ячейкой раздела 1 и сохраняются рядом с ноутбуком в `train.json`. Файл в репозиторий не коммитится.

## Задачи

Семь задач для самостоятельной работы в конце ноутбука: обрезка текста по длине, лемматизация только длинных слов, символьные n-граммы, подбор порога под заданный recall, фильтрация имён собственных, разметка отрицаний и NBSVM.

## Происхождение материала

Семинар основан на материале курса ML ВШЭ 2024 «Introduction to NLP» (авторы оригинала — Мария Тихонова, Евгений Соколов). Что изменено: бейзлайн идёт до предобработки; `pymorphy3` вместо `pymorphy2`, который не работает на Python 3.11+; лемматизация с кэшем вместо скачивания готового корпуса; вместо долгого `GridSearchCV` по нескольким параметрам — подбор только `C`; добавлены блоки об интерпретации и объяснении предсказаний, разборе ошибок, сравнении с деревьями и с наивным Байесом.
